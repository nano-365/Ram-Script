# Ram-Script
this script will decrease your ram usage (:

when you download this script ,make sure to run it as administrator rights or it will refuse to run.

SYSTEM MODIFICATION WARNING

This Software is designed to reduce RAM usage and clear memory caches
(including standby lists, working sets, and file cache). These operations
change system behavior and may cause temporary slowdowns or application
instability. You use this Software entirely at your own risk.


more about this script :

-when you run the script ,it will check if you're running as administrator rights 
-it calls RAMMap.exe to reduce RAM usage and clear memory caches (including standby lists, working sets, and file cache)
-and the script will run itself after every 5 minutes
